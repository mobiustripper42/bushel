## Task 1: Messages-for-Web auto-fill extension (closes #120)

**Completed:**
- `extensions/messages-for-web/{manifest.json, content-script.js, README.md, icon-{16,48,128}.png}` — sideloaded MV3 extension. - Icons resampled from `src/app/icon.png` (512px BBF leaf) to 16/48/128 via `sharp` — Pillow + ImageMagick both absent on mill-dev.
- `.vercelignore` — excludes `extensions/` from the Vercel bundle (file didn't exist before).
- `src/components/admin/send-row.tsx` — drops `noopener` on `window.open` (kills the window ref needed for postMessage; explicit origin allowlist on the content-script side is the equivalent guard). New `postToExtension` helper: one-shot message listener, 4s timeout, 800ms retry to cover the `document_idle` race. `recordOptimistic()` hoisted to run *before* the extension wait so the Sent pill flip isn't delayed 4s in the no-extension case (existing test's 5s timeout would have been tight). Now gated on a `settled` flag in the promise closure. Reviewer also cleared the `localhost:3001` origin (acceptable for single-operator threat model), Angular Material value-set (correct as-is), state matrix in `handleClick` (all four clipboard/tab/reply branches resolve correctly), and MutationObserver cleanup.
