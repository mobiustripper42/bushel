Bay Branch Farm

Inventory & Order System — Project Plan

Version: 2.0 (Post-Poker) Date: April 2026 Status: Approved for Build

1. At a Glance

A small, weekly-cadence ordering system for ~7 B2B customers (2 farm stands, 1 grocery store, 3–4 restaurants), replacing tend.com. Annabel posts what's available Sun/Mon, customers order, fulfillment is Wed/Thu by delivery (primary) or pickup (secondary).

v1 Effort

107 pts
102 pts if realtime ships dark

v1 Time

~16–37 hrs
Best case → conservative (sailbook velocity)
Velocity basis. Drawn from sailbook: best feature-work pace 0.15 hrs/pt (Session 89), conservative planning band 0.35 hrs/pt. Updates as bushel sessions accrue.

2. Tech Stack

Next.js 16 TypeScript strict Supabase Twilio (SMS) Vercel Playwright pgTAP

Customer-facing site lives at order.baybranchfarm.com. baybranchfarm.com stays Astro on Netlify, untouched.
